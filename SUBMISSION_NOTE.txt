WHAT THIS REPOSITORY CONTAINS
================================================================================

This repository contains the complete source code for the Hindi Handwritten
Document Recognition pipeline developed as the Group 39 final project for
ISY5004 Intelligent Sensing Systems.

Code is organised into four modules:

  annotation/     Multi-user Streamlit annotation portal
  detection/      YOLOv8 word detection scripts and training configs
  recognition/    TrOCR training, evaluation, and post-processing pipeline
  pipeline/       End-to-end batch pipeline, HITL review, monitoring

================================================================================
PROJECT SUMMARY
================================================================================

End-to-end OCR pipeline: scanned handwritten Hindi document -> Unicode text.

  Stage 1: YOLOv8s word detection (mAP@50: 0.78 -> 0.84 in v2)
  Stage 2: TrOCR word recognition — ViT encoder + RoBERTa-Hindi decoder
           (HindiSeg test CER: 8.17% -> 7.12% in v2)
  Stage 3: Text post-processing — Unicode NFC, LM rescoring, dictionary

End-to-end pipeline CER on Pratham evaluation pages: 51.8% -> 36.4% (v1->v2).
Field performance requires human-in-the-loop review; not production-ready for
unattended deployment.
